ThreeOS

ThreeOS — экспериментальная операционная система, создаваемая в рамках проекта GameBarry.

Проект предназначен для изучения принципов работы операционных систем, системного программирования, интерфейсов и взаимодействия программ с аппаратным обеспечением.

«🚧 ThreeOS находится в активной разработке.»

🎯 Цели проекта

- Изучение устройства операционных систем
- Разработка собственного системного интерфейса
- Работа с системными компонентами
- Изучение низкоуровневого программирования
- Постепенное создание собственной ОС с нуля

🛠️ Технологии

В зависимости от этапа разработки ThreeOS может использовать различные языки и технологии.

Основной упор проекта — на изучение Python, C/C++ и принципов системного программирования.
