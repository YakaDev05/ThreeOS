ThreeOS (Python-редакция)
Своя операционная система (в виде desktop-приложения) от Said (Yaka) Hamidov.
Python-порт ThreeOS на Python 3 + PySide6, без шага компиляции.
Весь исходный список готов
🧮 Калькулятор — арифметика, корректная обработка деления на ноль.
💻 Терминал — 20+ команд: help, man, ls, cd, pwd, cat, echo >, mkdir, touch, rm, mv, cp, find, tree, wc, head, tail, grep, calc, history, whoami, date, about, clear.
🗂️ Проводник — та же файловая система, что в Терминале, в графическом виде.
🌐 Браузер — настоящий Chromium (QWebEngineView): реальные сайты, ссылки, вкладки, назад/вперёд.
👤 Контакты — адресная книга + «Люди в сети» (LAN).
💬 СМС — реальная доставка: по номеру телефона через аккаунт-сервер (между любыми сетями) или напрямую по локальной сети (без сервера). Никакого автоответчика.
🛒 Магазин приложений (новое) — витрина всех приложений с описанием. Базовые — всегда с вами; необязательные (пока только Заметки) — устанавливаются и удаляются одним нажатием, и сразу появляются/пропадают с рабочего стола и из панели задач.
📝 Заметки (новое, устанавливается через Магазин) — быстрые заметки с автосохранением.
⚙️ Настройки (новое) — имя в локальной сети и доступ к аккаунту в одном месте.
Плюс: оболочка (загрузка → рабочий стол → окна), общая тема/шрифты, 70 автотестов без GUI (python -m unittest discover -v).
🔑 Аккаунт и доставка СМС по номеру телефона
Отдельный сервер server/threeos_server.py — чистый Python (asyncio), без Qt, можно запускать на любой машине.
Как попробовать вдвоём:
Кто-то запускает сервер там, куда оба могут достучаться:
python3 server/threeos_server.py --port 51950
Для проверки на одном компьютере подходит 127.0.0.1. Чтобы это работало между двумя разными компьютерами — сервер должен быть запущен там, куда оба могут достучаться (свой ПК + проброс порта на роутере, либо дешёвый/бесплатный VPS — например, Always Free тир Oracle Cloud, или $4–6/мес DigitalOcean/Linode).
В ThreeOS: СМС → «⚙ Аккаунт» (или Настройки) → адрес сервера → регистрация номером и паролем → вход.
Друг делает то же самое со своим номером на том же сервере.
Добавляете друг друга в Контакты по номеру — переписка настоящая. Если собеседник офлайн — сообщение встаёт в очередь и придёт, когда он войдёт.
Честно о безопасности: пароли хешируются (PBKDF2 + соль), но само соединение не шифруется (обычный TCP, без TLS) — годится для игры с друзьями, не для серьёзной приватной переписки.
Требования
Python 3.9+, PySide6 (requirements.txt) — движок браузера уже включён.
Установка и запуск
pip install -r requirements.txt
python main.py
Если pip требует флаг из-за "externally managed environment":
pip install -r requirements.txt --break-system-packages
Или через виртуальное окружение:
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python main.py
Если Браузер не грузит страницы на Linux (root/Docker)
QTWEBENGINE_CHROMIUM_FLAGS="--no-sandbox" python main.py
Если люди в сети (LAN) не находят друг друга
Один Wi-Fi/локальная сеть (не гостевая изолированная), файрвол не блокирует UDP 51999 / TCP 51998.
Где хранятся данные
~/.threeos/: contacts.json, messages.json, identity.json, server_config.json, filesystem.json, installed_apps.json, notes.json. Удали папку — сбросишь всё к демо-данным. На стороне сервера — server/server_data.json (аккаунты и очередь сообщений).
Структура проекта
ThreeOS-Python/
├── requirements.txt
├── main.py                     # запуск, тема, регистрация приложений
├── server/
│   └── threeos_server.py        # отдельный сервер аккаунтов (без Qt!)
├── core/
│   ├── iapp.py                   # интерфейс "приложения" (+ is_core())
│   └── theme.py
├── services/                    # общие данные и сеть между приложениями
│   ├── app_bus.py, identity.py, network_service.py, account_service.py
│   ├── contacts_store.py, messages_store.py, notes_store.py
│   └── installed_apps_store.py    # что установлено через Магазин
├── shell/                       # рабочий стол, панель задач, реестр приложений
├── apps/
│   ├── calculator/, terminal/, explorer/, browser/
│   ├── contacts/, sms/, settings/, notes/
│   └── appstore/                  # Магазин приложений
├── tests/                       # 70 автотестов логики (без GUI)
└── resources/fonts/
Чтобы добавить новое приложение: создать папку в apps/, реализовать класс с IApp (не забыть is_core(), если оно необязательное), и одну строку в register_apps() в main.py — оно сразу появится в Магазине.
